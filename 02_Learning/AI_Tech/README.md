# AI and Technical Learning

## Module Responsibility

- Track independent learning about AI tools.
- Track software engineering and full-stack development learning.
- Track Git and developer workflow learning.
- Track technical topics outside direct HAL coursework.

## What Belongs Here

- AI-assisted development workflow learning.
- ChatGPT, Claude Code, and Codex usage learning.
- Software engineering concepts under active study.
- Full-stack development learning outside direct product implementation.
- Git and developer workflow learning.

## Boundaries

- Real product implementation belongs in `03_Project`.
- Stable reusable material belongs in `05_Reference`.
- HAL coursework belongs in `02_Learning/HAL`.
- Daily execution belongs in `04_Daily`.

## Operating Rules

- Do not create speculative subfolders.
- Record confirmed learning activity rather than assumed mastery.
- Use `Not Confirmed` or `Unknown` when information is missing.
- User-authored notes should not be silently replaced by polished AI summaries.
- Keep active learning notes concise and easy to continue.
