# Learning

## Module Responsibility

- Track active learning areas.
- Maintain current learning status.
- Organize HAL coursework.
- Organize independent AI and technical learning.
- Help Human and AI collaborators understand what is currently being learned.
- Prevent repeated teaching and unnecessary restarting.

## What Belongs Here

- Current learning priorities.
- Confirmed learning progress.
- HAL coursework status.
- Independent AI and technical learning status.
- Learning gaps that need attention.
- Notes that help future study continue from the right place.
- User-authored learning notes that AI may review.

## What Does Not Belong Here

- Career goals, which belong in `01_Career`.
- Real software products, which belong in `03_Project`.
- Daily actions, which belong in `04_Daily`.
- Stable reusable reference material, which belongs in `05_Reference`.

## Operating Rules

- Do not assume completion. Record only confirmed progress.
- Learning status should be updated from real study activity, not from speculative plans.
- Use `Confirmed`, `In Progress`, `Not Started`, `Not Confirmed`, or `Unknown` when status clarity is needed.
- Preserve uncertainty when repository evidence, user confirmation, or source material is insufficient.
- Accuracy is more important than completeness.
- Acceptable evidence includes explicit user confirmation, repository evidence, actual lesson records, provided course materials, provided screenshots, and provided recordings or transcripts.
- Do not convert exposure to a topic into mastery.
- Do not mark anything complete without explicit evidence.
- Do not assume prerequisites are understood.
- Keep this module focused on active learning state.
- Avoid duplicating stable reference material.
- Update current status before asking an AI to continue teaching from past context.

## User-Authored Notes Rule

- The user writes final learning notes personally.
- AI may review notes, identify factual errors, identify missing concepts, ask targeted questions, and provide small corrections.
- AI should not silently replace user notes with a polished AI-generated version.
- AI-generated summaries are supplementary and must not replace user-authored notes.
- After a lesson or learning unit, hand off explicitly to the relevant `Notes.md` file.
